Functions and Features

Rich features support smooth information sharing within your company and team. Here are some of GROWI's useful features.
For details, see GROWI Docs/Features.

Markdown support

Paragraphs, headings and bullet points are easy to write. GROWI also supports a rich text editor, syntax highlighting for each programming language, emoji, footnotes, to-do lists, math formulas, UML and Bootstrap (HTML).

Create Diagram

GROWI integrates with draw.io, so you can create diagrams easily on GROWI. Diagrams help you share information that is difficult to express in writing.

Tag and Full-text search

Full-text search covers the titles of uploaded files as well. Alphanumeric characters match in both full-width and half-width forms.

Simultaneous multi-user edits

Multiple users can edit a single page at the same time, which is useful for taking meeting minutes. Edits are saved automatically, and past revisions can be viewed.

Highly customizable

You can choose themes and layouts, and even customize the sidebar, which is rare among similar services. Flexible settings let you match the way your team works.

Group Management

You can grant administrator privileges to specific users and set page viewing permissions for each user group.

Comment Features

Each page shows comments in threads. Comments can be written in Markdown, previewed, and can have files attached.

Powerful authentication mechanism

GROWI's authentication is built on Passport. It supports single sign-on (SSO) with SAML and OpenID Connect (OIDC), LDAP authentication, and login through GitHub and Google OAuth providers.

Simple asset management

Upload files simply by dropping them into the editing screen. GROWI supports five storage types: local file system, AWS S3, Google Cloud Storage, Azure Blob Storage and MongoDB GridFS.

Starting with version 8.0.0, GROWI AI has been reborn as GROWI AI Agent.
No assistants to create, no training required. Just ask a question, and it explores your entire wiki on its own, gathers evidence, and builds an answer.

Explores your entire wiki to answer

Ask a question, and it autonomously explores and cross-references related pages to gather evidence and answer. Specify pages with @ to narrow down the scope.

It always refers to the latest pages. Access permissions are checked at access time, so pages you cannot view are never used.

Choose your own provider and model

Register an API key to choose from OpenAI, Anthropic, Google, and Azure OpenAI as your provider.

Users switch models from the sidebar, and administrators can narrow down the models available in advance.

Setup and Management

GROWI MCP Server

GROWI provides a server that supports the Model Context Protocol (MCP). Register it with a client such as Claude Code, and agents can search, view, create, and update pages directly.

Benefits of adopting GROWI

Able to manage information and knowledge in one place

GROWI lets you manage and share information and knowledge easily by consolidating business-related information in one place.

Find the information you want quickly

With the search features, you can easily find the information you need. This helps prevent work from depending on a single person and creates a more collaborative working environment for the team.

Turn individual knowledge into team growth

The knowledge, skills and experience that individuals gain from their work are essential assets for the growth of organizations and teams. By sharing, storing and using this knowledge, organizations can develop even further.
