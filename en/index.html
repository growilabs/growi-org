A wiki readable by people and AI alike

Markdown native

Every page is plain Markdown. Paragraphs, headings and bullet lists are easy to write, and it supports a rich text editor, code highlighting for each programming language, emoji, footnotes, TODO lists, math, UML and Bootstrap (HTML). Append .md to a page URL to fetch its body as raw Markdown, so AI agents can read a page with a single GET.

See the Markdown syntax

Embedded diagrams

Besides intuitive drawing with draw.io, diagrams written in Mermaid or PlantUML notation can be embedded in Markdown as plain text. Share ideas that are hard to put into words clearly with diagrams.

Rich APIs and an MCP server

GROWI MCP Server

GROWI provides a server that supports the Model Context Protocol (MCP). Register it with a client such as Claude Code, and agents can search, view, create, and update pages directly.

What it can do

  • Search and retrieve pages
  • Create, update and manage pages
  • Manage tags, comments and share links
  • Connect to multiple GROWI apps
Learn more
growilabs/growi-mcp-server @growi/mcp-server

GROWI v7.3.x or later is recommended. Works with clients such as Claude Desktop, Claude Code and Gemini CLI.

REST API

GROWI provides a REST API for working with pages, users, attachments and more, so you can flexibly integrate it with your existing tools and workflows.

API Reference

Starting with version 8.0.0, GROWI AI has been reborn as GROWI AI Agent.
No assistants to create, no training required. Just ask a question, and it explores your entire wiki on its own, gathers evidence, and builds an answer.

Explores your entire wiki to answer

Ask a question, and it autonomously explores and cross-references related pages to gather evidence and answer. Specify pages with @ to narrow down the scope.

It always refers to the latest pages. Access permissions are checked at access time, so pages you cannot view are never used.

Choose your own provider and model

Register an API key to choose from OpenAI, Anthropic, Google, and Azure OpenAI as your provider.

Users switch models from the sidebar, and administrators can narrow down the models available in advance.

Setup and Management

GROWI Vault

git clone your wiki.

Fetch the pages you have permission to view as a tree of Markdown files in a Git repository.

Keep it up to date with git pull, or fetch only some pages with sparse checkout.

AI coding agents can explore the wiki just like local files.

git clone https://x:<ACCESS_TOKEN>@<GROWI_HOST>/vault.git

Read-only. Available in self-hosted environments when enabled by an administrator.

Other Functions and Features

GROWI also has many other features that support smooth information sharing within your company and team.
For details, see GROWI Docs/Features.

Tag and Full-text search

It can search Full-text include the title of the uploaded file.The alphanumeric can be searched with either full-width or half-width characters.

Simultaneous multi-user edits

A single page can be edited by multi users simultaneously. It'll be useful when compiling minutes of Meeting. Furthermore, it can automatically save edits and allow viewing of past revisions.

Highly customizable

It allows users to select themes and layouts, and offers customization of the sidebar, which is rare compared to other services. Flexible settings are available to match the usage of your team.

Group Management

It is possible to grant administrator privileges to specific users and to set viewing permissions for pages by user groups.

Comment Features

It is possible to display comments in a threaded format for each page on the website. Comments can be written in Markdown format, previewed, and files can also be attached.

Powerful authentication mechanism

Our system implements an authentication mechanism using Passport, and supports single sigh-on(SSO) using SAML, LDAP authentication, and login through GitHub/Twitter/Google OAuth provider.

Asset management as simple

We can upload files simply by dropping them into the editing screen. The system supports storage on one of four types: local FS, AWS S3, Google Cloud Storage, MongoDB GridFS.

Merit of introduction

Able to manage information and knowledge in one place

GROWI allows you to easily manage and share information and knowledge by consolidating business-related information in one place.

Get the information what you want quickly

By utilizing the search features, it is possible to easily find the desired information. This helps prevent personalization of tasks and creates a more collaborative working environment for the team.

Leveraging individual knowledge for team growth

The knowledge, skills, and experience that individuals gain from their work are essential assets for growth of organizations and teams. By sharing, storing, and using this knowledge, organizations can develop even further.
