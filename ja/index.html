人にも、AI にも読みやすい wiki

Markdown ネイティブ

ページの実体は Markdown そのもの。段落や見出し、箇条書きの記入も簡単で、リッチテキストエディタ、プログラミング言語ごとのコードハイライト、絵文字、注釈、TODOリスト、数式、UML、Bootstrap(HTML) にも対応しています。ページの URL に .md を付ければ本文を Markdown のまま取得できるので、AI エージェントも 1 回の GET でページを読み取れます。

Markdown 記法を見る

図形の埋め込み

draw.io による直感的な作図に加え、Mermaid や PlantUML の記法で書いた図も、テキストのまま Markdown の中に埋め込めます。文章では表現しにくい内容も、図を用いて伝わりやすく共有できます。

豊富な API と MCP サーバー

GROWI MCP Server

GROWI は Model Context Protocol (MCP) 対応のサーバーを提供しています。Claude Code などのクライアントに登録すれば、エージェントがページの検索・閲覧・作成・更新を直接実行できます。

できること

  • ページの検索・取得
  • ページの作成・更新・管理
  • タグ・コメント・共有リンクの管理
  • 複数の GROWI アプリへの接続
詳しく見る
growilabs/growi-mcp-server @growi/mcp-server

GROWI v7.3.x 以降を推奨。Claude Desktop・Claude Code・Gemini CLI などから利用できます。

REST API

ページやユーザー、添付ファイルなどを操作できる REST API を備えています。既存のツールやワークフローとの連携を柔軟に組めます。

API リファレンス

バージョン 8.0.0 より、GROWI AI は GROWI AI Agent として生まれ変わりました。
アシスタントの作成も学習も不要。質問を投げるだけで、wiki 全体を自ら探索して根拠を集め、答えを組み立てます。

wiki 全体を、自ら探索して答える

質問を投げると、関連するページを自律的に探索・横断参照して根拠を集め、回答します。@ でページを指定すれば、参照範囲を絞り込めます。

参照するのは常に最新のページ。閲覧権限もアクセス時に判定され、権限のないページは使われません。

プロバイダとモデルは、自分で選ぶ

API キーを登録すれば、OpenAI・Anthropic・Google・Azure OpenAI からプロバイダを選択できます。

モデルはユーザーがサイドバーで切り替え、管理者は使わせたいモデルを事前に絞り込めます。

セットアップと管理

GROWI Vault

wiki を、git clone する。

自分が閲覧権限を持つページを、Markdown ファイルのツリーとして Git リポジトリで取得できます。

git pull で最新化でき、sparse checkout で一部のページだけを取得することも可能。

AI コーディングエージェントが、手元のファイルと同じように wiki を探索できます。

git clone https://x:<ACCESS_TOKEN>@<GROWI_HOST>/vault.git

読み取り専用。self-hosted 環境で管理者が有効化した場合に利用できます。

使い方を見る 管理者向けセットアップ

その他の機能と特徴

このほかにも、社内やチーム内でのスムーズな情報共有を支える機能を豊富に備えています。
機能の詳細は、GROWI Docs/機能紹介 をご覧ください。

タグ検索・全文検索

アップロードされたファイルタイトルを含めた文検索が可能です。英数字は全角半角どちらでもヒットするようになっています。

同時多人数編集

一つのページを複数人で同時に編集可能です。会議の議事録を取るときなどに便利です。また、編集履歴を自動保存し、過去の履歴を閲覧することも出来ます。

優れたカスタマイズ性

テーマ、レイアウトを選択できる他、他のサービスと比べても数少ない、サイドバーのカスタマイズにも対応しています。チームの使い方に合わせた柔軟な設定が可能です。

グループ管理

特定ユーザーに管理者権限の付与、ユーザーグループごとのページの閲覧権限が可能です。

コメント機能

ページ毎にコメントをスレッド表示できます。コメントも Markdown による記述・プレビュー、またファイル添付が可能です。

強力な認証機構

Passportによる認証機構を採用、SSO を実現する SAML や、LDAP 認証、GitHub/Twitter/Google OAuth プロバイダを利用したログインをサポートしています。

シンプルなアセット管理

編集画面にドロップするだけで、ファイルをアップロード出来ます。ストレージはローカルFS、AWS S3、Google Cloud Storage、MongoDB GridFS の4種をサポートしています。

導入のメリット

情報やナレッジをまとめて管理できる

社内では議事録や報告書、業務マニュアルなど多様な情報が存在します。GROWIを活用し、業務に関わる情報を一つの場所にまとめることで、簡単に情報やナレッジを管理、共有できるようになります。

欲しい情報がすぐに手に入る

検索機能を利用することで、簡単に知りたい情報を探し出すことが可能です。また、業務の属人化を防ぎ、チームとして働きやすい環境を作ります。

個人が持っている情報を
チームの発展に繋げる

個人が持つノウハウや知識、仕事をする中で得た経験は、企業やチームとって、組織の成長に欠かせない重要な財産です。ノウハウを共有・蓄積・活用することで組織のさらなる発展へとつながります。
